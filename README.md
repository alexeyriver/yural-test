# Поиск автозапчастей и аналогов

SPA для двухэтапного подбора запчастей через [Favorit Parts API](https://lk.favorit-parts.ru/static/wsprice.pdf):

1. Пользователь вводит артикул — приложение показывает производителей, у которых есть деталь с этим номером.
2. Пользователь выбирает производителя — приложение показывает таблицу предложений по самой детали и её аналогам: производитель, номер, название, цена, остаток, склад, дата отгрузки.

Стек: React 19, Redux Toolkit, Bootstrap 5, Vite. Тесты — Vitest и React Testing Library.

## Запуск

Нужен Node.js 22.13 или новее.

```bash
npm install
npm run dev        # http://localhost:5173
```

Ключ API берётся из переменной `VITE_FAVORIT_KEY`. Без неё используется демо-ключ `00000000-0000-0000-0000-000000000001`, поэтому `.env` для запуска не обязателен. Чтобы указать свой ключ:

```bash
cp .env.example .env   # и вписать ключ
```

После изменения `.env` dev-сервер нужно перезапустить.

## Как устроено

```
components ──dispatch(thunk)──▶ store (Redux slices) ──▶ api/favoritApi.js ──▶ fetch
           ◀────useSelector────                        ◀── api/normalize.js
```

- `src/api/favoritApi.js` — запрос к API и обработка ошибок: сеть, ответ с `error`, не-JSON, HTTP-статус.
- `src/api/normalize.js` — чистые функции: ответ API → список брендов / строки таблицы, перевод ошибок.
- `src/store/` — два slice-а: `brands` (этап 1) и `offers` (этап 2); статусы загрузки — `STATUS` из `src/constants.js`.
- `src/components/` — форма поиска, список брендов, таблица предложений и общие `Loader`, `ErrorAlert`, `EmptyState`.
- `src/hooks/useLatestThunk.js` — запускает запрос, отменяя предыдущий того же типа.

## Ограничения

- **Ключ API виден в клиентском бандле.** Для продакшена нужен бэкенд-прокси, который хранит ключ и ходит в API сам. Для тестового задания оставлен клиентский вызов.
- Нет серверной пагинации: API всегда отдаёт все аналоги одним ответом.
- У API есть квота запросов (`Request quota exceeded!`); приложение показывает понятную ошибку, но не ограничивает частоту запросов само.

## Ручная проверка

| Что сделать                               | Что ожидать                                                                                               |
| ----------------------------------------- | --------------------------------------------------------------------------------------------------------- |
| Ввести `01089`, выбрать ASAM              | список брендов по алфавиту; таблица, первой строкой — искомая деталь с бейджем «Оригинал», дальше по цене |
| Снять «Только в наличии»                  | в конце появляются строки «нет в наличии» без цены                                                        |
| Ввести `7160500039S`, выбрать MEYLE       | первые 100 строк из нескольких тысяч и кнопка «Показать ещё 100»                                          |
| Ввести `7260500039S`                      | «Производители не найдены»                                                                                |
| DevTools → Network → Offline, поиск       | «Нет связи с сервером…» и кнопка «Повторить»                                                              |
| Неверный ключ в `.env`, перезапуск, поиск | «Неверный ключ API»                                                                                       |
| Ширина 375px                              | блоки друг под другом, таблица прокручивается внутри своего блока                                         |
